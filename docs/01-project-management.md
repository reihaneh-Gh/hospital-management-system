## سیستم اتوماسیون و نوبت‌دهی هوشمند بیمارستانی

## ۱. تابلوی مدیریت پروژه (Kanban Board)

پیوند تابلوی مدیریت پروژه در GitHub Projects:

[مشاهده بورد مدیریت پروژه](https://github.com/users/reihaneh-Gh/projects/3/views/1?layout_template=board)

این بورد برای سازمان‌دهی و پیگیری فعالیت‌های پروژه استفاده می‌شود و شامل سه ستون است:

- **To Do:** فعالیت‌هایی که هنوز شروع نشده‌اند.
- **In Progress:** فعالیت‌هایی که در حال انجام هستند.
- **Done:** فعالیت‌هایی که تکمیل شده‌اند.

## ۳. زمان‌بندی اولیه پروژه (Preliminary Project Schedule)

| فاز پروژه | فعالیت‌های اصلی | زمان تخمینی |
|---|---|---|
| آغاز پروژه (Initiation) | تعیین اهداف، شناسایی ذی‌نفعان و تدوین منشور پروژه | ۱ هفته |
| برنامه‌ریزی (Planning) | امکان‌سنجی، تعیین محدوده، تهیه فهرست کارها و برنامه‌ریزی منابع و زمان | ۲ هفته |
| اجرای پروژه (Execution) | تحلیل نیازمندی‌ها، ترسیم نمودارها، طراحی پایگاه داده و نمونه‌های اولیه رابط کاربری | ۵ هفته |
| خاتمه پروژه (Closedown) | بازبینی نهایی، تکمیل مستندات و تحویل پروژه | ۱ هفته |

**مدت‌زمان تخمینی کل: ۹ هفته**

این برنامه، زمان‌بندی اولیه پروژه است و در صورت نیاز، با توجه به پیشرفت فعالیت‌ها بازبینی خواهد شد.

## ۴. پیگیری پیشرفت پروژه

پیشرفت فعالیت‌ها از طریق بورد GitHub Projects پیگیری می‌شود. وضعیت هر فعالیت با انتقال آن بین ستون‌های بورد به‌روزرسانی خواهد شد. تغییرات مهم در محدوده و زمان‌بندی پروژه نیز ثبت و بررسی می‌شوند.
